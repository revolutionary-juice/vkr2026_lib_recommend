## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/revolutionary-juice/vkr2026_lib_recommend.git
cd vkr2026_lib_recommend
```

### 2. Создать базу данных PostgreSQL

Открыть pgAdmin или psql и выполнить:

```sql
CREATE DATABASE vkr_db;
```

Пользователь по умолчанию: `postgres`, пароль: `123456`.

Если у вас другой пользователь или пароль — отредактируйте строку подключения в файле `app/core/database.py`:

```python
DATABASE_URL = "postgresql+psycopg2://postgres:123456@127.0.0.1:5432/vkr_db"
#                                      ^логин  ^пароль
```

### 3. Настроить и запустить бэкенд

```bash
# Создать виртуальное окружение
python -m venv .venv

# Активировать (Windows)
.venv\Scripts\activate

# Активировать (Mac / Linux)
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
uvicorn app.main:app --reload
```

Бэкенд запустится на `http://127.0.0.1:8000`

При первом запуске:
- Все таблицы БД создаются автоматически
- Автоматически создаётся учётная запись администратора

### 4. Запустить фронтенд

Открыть **второй терминал**:

```bash
cd frontend
npm install
npm run dev
```

Фронтенд запустится на `http://localhost:5173`

## Возможные проблемы

**Ошибка подключения к БД**
- Убедитесь что PostgreSQL запущен
- Проверьте логин/пароль в `app/core/database.py`
- Убедитесь что база данных `vkr_db` создана

**Фронтенд не подключается к бэкенду**
- Убедитесь что бэкенд запущен на порту 8000
- Убедитесь что фронтенд запущен на порту 5173 (CORS настроен именно на этот порт)

**`pip install` падает на psycopg2**
- Установите отдельно: `pip install psycopg2-binary`
- Или установите PostgreSQL dev-библиотеки для вашей ОС
